# AI Playground

This repo contains mini-projects I've built with AI coding assistants (mostly Claude so far) to explore what's possible. You can see them at https://mwanberg.github.io/ai-playground/.

Most of the code comes from vibe coding. I described in natural language what I wanted to end up with, and the assistant wrote it. I sometimes guided it in different ways, such as telling it a good order to build things in, or asking for changes, but a lot of this it just figured out on its own.

These are experiments so they aren't polished and I didn't build them to be accessible.

Each one has its own folder with an `index.html` and no build step, so you can also open any of them straight from a clone.

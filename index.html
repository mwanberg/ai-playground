AI Playground

Here are a few mini-projects I've built with AI coding assistants to explore what's possible. Most of the code comes from vibe coding. I described in natural language what I wanted to end up with, and the assistant wrote it. Sometimes I guided it in different ways, such as telling it a good order to build things in, or asking for changes.

You can find the code for everything on the repository page for AI Playground on GitHub (opens in a new tab). Please feel free to take and use as much of it as you want. Let me know if you make anything fun!

These little projects are creative experiments. In creative work, I often get messy and try unusual things. Unlike sites and tools that people need to use (which is what I normally build), these aren't always polished.

Projects marked with aren't designed to be accessible, so user beware.

  • Christmas Illustrations

    After the UI Theme Explorer showed me Claude could make passable one-shot SVG representations, I wanted to see if it could do more complicated images that looked better. With a lot of guidance, it made a set of Christmas illustrations in a retro-ish style. It includes ornaments, greenery, gifts, scenes, and UI elements like banners and frames. You can copy each one as SVG or HTML. Opus 5.5 (medium effort)

    Created October 19, 2026

  • UI Theme Explorer (not designed to be accessible)Not designed to be accessible

    I asked Claude Opus 5.5 (high effort) for a set of interface components (buttons, forms, cards, data tables, etc.) and then used natural language to essentially one-shot 14 different theme variations. The themes include a calm SaaS look, a coral reef, and glam glitter. Each theme also has a dark mode to explore. WARNING: might hurt your eyes.

    Created October 19, 2026

  • Font Explorer

    A tool for pairing a heading font with a body font from Google Fonts. I built it with Claude Sonnet 5 (medium effort) and updated it with Claude Opus 5.5 (high effort). Adjust size, weight, and spacing, try pairings grouped by style (Art Deco and 1980s synthwave among them).

    Created September 10, 2026

  • Aurora (not designed to be accessible)Not designed to be accessible

    An interactive musical night sky. Drag to paint curtains of aurora with chimes playing as you go. An early exploration stemming from a late night request to Claude Opus 4.8 to "make me something sparkly." Might be a little heavy in your browser. Sometimes the sound is buggy, especially on iPhones.

    Created July 28, 2026
